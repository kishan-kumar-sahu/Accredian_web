MERN Stack Web Application
📌 Project Overview

This is a full-stack web application built using the MERN stack (MongoDB, Express.js, React, Node.js). The project focuses on creating a structured, scalable, and responsive web platform with proper backend APIs and frontend UI components.

📂 Project Structure
